# Aghanim Homebrew Tap

Homebrew packages for Aghanim command-line tools.

## Aghanim CLI

Command-line interface for the Aghanim Server-to-Server API.

Install:

```bash
brew install aghanim-dev/tap/aghanim
```

Upgrade:

```bash
brew update
brew upgrade aghanim
```

Get started:

```bash
aghanim login
aghanim --help
```

Documentation: https://docs.aghanim.com
